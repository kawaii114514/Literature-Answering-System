# 检索评测

本文件只记录可复现的真实评测结果。当前仓库提供评测协议、运行器和小型 fixture；完整公开论文集和人工标注完成后，才填写准确率或性能结论。

## 固定评测协议

- 首版使用 10–20 篇公开 AI、机器学习或信息检索英文论文。
- 先标注 20 条问题打通流程，再扩展到至少 50 条；约 20% 为应当拒答的问题。
- 每条数据包含问题、判断标准、证据文献、证据页码和原文片段。
- 向量基线、混合检索、混合检索加重排必须使用相同文档、问题、模型、参数和运行环境。
- 记录 Recall@K、引用正确率、回答/拒答准确性、平均与 P95 检索耗时、模型耗时、Token 和调用成本。

## 运行环境

待首次评测时记录 CPU、内存、操作系统、容器镜像、模型名称、模型版本、Embedding 维度、分段参数、Top-K 和阈值。

## 原始结果

运行器：`python scripts/evaluate.py --dataset evaluation/dataset.jsonl --space-id <spaceId> --output evaluation/results.json`。

待构建固定评测集后，在此加入机器可读原始输出位置、运行时间戳、容器镜像和计算脚本版本；Top-5 基线值和提升值只引用该结果。
