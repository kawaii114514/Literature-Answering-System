# 纸上研究室

2026-11-16，前端视觉与交互改造。

## 设计 brief

面向研究生与课题组，以“提出问题 → 阅读回答 → 核对原文 → 留下研究摘录”为主要任务。采用学术期刊与案头笔记的视觉语言：暖纸白阅读面、墨绿操作、少量朱砂引用标记；书刊式标题配清晰的无衬线正文。左侧保留研究主题与会话索引，中间为阅读区，右侧文献与摘录可收起，专注模式提供居中阅读布局。

保留现有 React / TypeScript / Vite 技术栈与服务接口。不引入外部字体请求或装饰图像依赖。减少重复容器、英文技术术语和与阅读任务竞争的指标。

## 使用方式

- **快速跳转**：Ctrl / ⌘ K，搜索知识空间、当前空间的历史会话或研究行动；方向键选择，Enter 跳转，Esc 关闭。
- **专注阅读**：右上角展开图标隐藏导航与文献栏；再次点击退出。
- **原文侧注**：点击当前回答里的引用编号，在弹窗中核对文献标题、页码与原文。
- **研究摘录**：点击“收藏证据”，在右侧“摘录”中查看、移除或导出 Markdown。按当前账户与知识空间存放在浏览器本地，不会跨设备同步；清理浏览器数据前应先导出。
- **导出回答**：回答完成后，导出正文及保持原编号的引用证据。
- **案头文献**：按标题、作者或原文件名即时搜索，可切换最近添加或标题排序。
- **提问入口**：寻找共识、对比方法、发现空白会填入可编辑的问题，不自动提交。

检索方式仍映射到现有接口：语义 → VECTOR，混合 → HYBRID_RRF，深度 → HYBRID_RERANK。默认混合检索；深度检索需要配置重排服务。

## 可访问性与交互边界

中文输入法确认文字时不会误发问题。弹窗支持焦点循环、Esc 关闭和关闭后焦点恢复。动效遵循系统减少动态效果设置。窄屏使用抽屉式导航和文献栏。切换空间或会话时取消旧回答，避免旧流内容写入新页面。

历史会话接口目前只返回消息文字，不能恢复引用详情；原文侧注和收藏入口仅用于当前有引用数据的回答。已收藏摘录可独立保留。

## 第二轮：像素书房（2026-11-20）

在第一轮"纸上研究室"之上加一层克制的像素语言：纸面阅读区保持原样，像素只出现在可以摸的东西上——书架、咕咕（猫头鹰管理员）、按钮、状态标记和动效。

### 设计 brief

- 用户与任务不变：提出研究问题、核对原文、收藏证据。像素不是新界面，而是研究台上多了一位管理员和一座真的书架。
- 目标感受：安静的书房里有一点会动的小东西；忙的时候它是状态，闲的时候可以戳。
- 视觉隐喻：文献列表 = 书架。每篇文献按 ID 稳定地生成一本书：布面色、书脊花纹、高度由哈希决定，厚度随页数增长；状态直接写在书上：处理中发灰扫描、失败时倾倒并挂 ! 牌、被引用时插上编号书签、检索时整排书依次弹跳。
- 排版：像素字体（Fusion Pixel 12px，SIL OFL）只用于短标签、计数和书脊，12px / 24px 两种字号保持清晰；正文与标题仍是衬线体与无衬线体。
- 动效：全部基于 CSS 与 Web Animations，没有新增运行时依赖；点击类动效是一帧一帧的 steps 缓动，不是平滑补间。

### 交互与动效清单

| 位置 | 交互 | 反馈 |
| --- | --- | --- |
| 文献库 | 拖 PDF 到窗口任意位置 | 全屏"松手，上架"遮罩；文献面板自动打开；占位书出现，像素书飞入书架并落地扬尘 |
| 文献库 | 选择 PDF | 同上的占位与落地，从按钮起飞；列表视图下飞向列表顶部的添加行；文献栏收起时会先自动打开 |
| 文献库 | 索引任务进行中 | 书脊扫描、任务卡八段进度条、完成时书跳起撒花、咕咕说一句"新书上架" |
| 文献库 | 失败 | 书倾斜并挂 `!` 牌，任务卡显示原因 |
| 文献库 | 点击书 | 书被抽出，下方展开"借阅卡"：标题、作者、年份、页数、状态、引用编号、删除、"就这篇提问" |
| 文献库 | 键盘 | 书是原生按钮，Tab / Enter 可用；书架 / 列表视图切换会记住选择 |
| 文献库 | 搜索 | 不匹配的书变暗下沉，保留空间感；列表视图同步过滤 |
| 书架 | 拖书到输入框 | 输入框高亮，自动填好针对这篇文献的问题 |
| 回答 | 检索中 | 书架整排扫描，正文区出现"放大镜扫过书脊"场景，咕咕左右张望 |
| 回答 | 引用 | 引用编号带对应书的布面色；悬停或聚焦编号会从书架抽出那本书，打开原文侧注期间保持抽出 |
| 回答 | 收藏证据 | 书签精灵飞向右侧"摘录"标签并计数跳动 |
| 提问 | 发送 | 小纸条飞向咕咕，咕咕进入写作状态；流式光标改为像素方块 |
| 全局 | 删书 / 移除摘录 | 书消失处扬起像素尘土 |
| 全局 | 动效开关 | 侧栏"动效"开关，默认跟随系统 `prefers-reduced-motion`；关闭后所有 CSS 动画与 JS 飞行都停止，功能不变 |
| 侧栏 | 案头绿植 | 按当前空间的会话数分四个阶段长大，可点击浇水；复制成员 ID、新建空间等操作在原处迸出粒子 |
| 登录 | 密码输入 | 咕咕用翅膀捂住眼睛；出错时眩晕 |

### 减少的文字引导

- 上传区的大段说明改为"书架上的空位"，限制信息收进 tooltip 与一行小字。
- 侧栏座右铭换成会生长的绿植；空会话提示缩成一行。
- 输入框下方的免责声明改为盾牌按钮：点一下由咕咕说出来（触屏同样可用）；快捷键说明收进发送按钮 tooltip 和咕咕的提示。
- 各页英文 eyebrow 与装饰性段落基本移除；解释性文字改为"用了才会出现"的提示气泡。
- 试用说明在登录页完整展示（首次同意），在文献库中折叠为一行摘要。

### 工程与资源

- 新增：`src/pixel/`（sprites 文本网格、`PixelSprite` 渲染、`Owl`、`effects`、`DeskPlant`）、`src/components/Bookshelf.tsx`、`DropOverlay.tsx`、`src/library.ts`（书脊、引用旗标、拖拽载荷的纯函数）、`src/pixel.css`。
- 像素字体经 `scripts/subset-pixel-font.py` 子集化：拉丁 13 KB + 中文（GB2312）177 KB，按 `unicode-range` 自动按需加载；许可证在 `public/licenses/fusion-pixel-font/`，随构建产物分发。
- 动效层 `#fx-layer` 脱离 React 渲染一次性元素，动画结束即移除，不残留节点。
- 关闭动效时不做任何飞行/粒子计算；`data-motion` 在首次渲染前设置，避免闪烁。
